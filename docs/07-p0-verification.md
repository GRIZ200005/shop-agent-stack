## 本轮修复与可证明贡献

1. 订单详情原实现直接按 ID 查询：增加当前客户归属检查，拒绝时不加载明细。
2. 下单增加地址归属校验和空购物车校验。
3. smoke 以 0.01 元伪造购物车价格，发现无优惠路径沿用客户端价格：促销计算前统一读取 SKU 权威价格，并验证数量和 SKU。
4. 建立独立随机配置、公开上游来源记录、纯 DDL 提取、自建合成种子、构建/启动/停止及两层验收脚本。

以上属于 Aster 增量；原有商城 CRUD、会员、购物车、订单等主体由 mall 提供。没有将上游体量当作个人贡献。

参见 06 运行手册。原始构建日志 `.local/build.log`，API 报告 `.local/p0-smoke.json`，Surefire 报告位于 portal 的 target/surefire-reports。原始文件与凭据被 Git 忽略，本文仅记录已检查的结果。
