# P3a：正式政策检索与引用闭环

更新：2026-09-15。基础政策 RAG 已实现；不等于完成 Hybrid、重排、有界证据充分性子图或真实模型效果验收。

## 功能与操作

管理员在管理中心新建政策，选择客户或内部可见，保存草稿。点击发布后，Java 在一个 MySQL 事务内生成条款与 SHA256、标记 READY 并发布；失败则整体回滚，草稿不对客户可见。界面显示索引状态和条款数。

已发布政策可修订为新的草稿。发布新版本时原版本标为 SUPERSEDED，保持历史正文；旧草稿不能覆盖已发布过的更高版本。撤回只影响当前正式可见性，不删除历史记录。版本家族行锁串行化发布、修订编号和撤回。

客户在助手询问政策时，模型可调用 `search_policies`，通过真实 MCP 从 Java 分页读取当前正式条款。每页 200 条，最多 100 页，超预算明确失败，不静默截断。目录 epoch 在发布和撤回时更新；分页面读取发生变化则拒绝混合快照。

Python 使用 LangChain Core Document 与 BM25 中文字符二元组基线检索前五条。这里暂不使用缓存或异步任务，牺牲部分吞吐以先验证正确性；每次从 MySQL 权威目录构建内存词法索引。后续引入持久化向量索引、队列和缓存时必须保留同等版本门槛。

模型用 `[P政策IDV版本C条款号]` 标注依据。宿主仅接受本轮检索出现过的标识，并在返回最终政策回答前通过宿主专用 MCP 工具重新读取版本、核对条款哈希。模型不能发现或调用宿主专用引用校验工具。

带政策证据的生成正文先缓冲，校验通过后才展示，以避免生成中撤回的内容先显示为有效回答；普通业务回答仍逐段流式展示。界面给出可展开的工具过程和原文卡片。原文链接精确到版本与条款，打开时再次验证可见性，旧版或撤回后显示不可访问。

引用检查证明来源存在、版本有效和文字未变化，**不证明模型的每句话都被原文支持**。语义支持率仍需评测及人工抽查。历史对话保留作答时的引用快照，不会因后续撤回改写历史；重新打开来源时核实当前有效性。生成完成后的政策变更也无法追溯撤销已经展示的回答。

## 数据边界

- 迁移 `005-p3-policies.sql` 保留现有已发布政策，补齐元数据与初始条款，不发布 48 篇编写草案。
- 48 篇草案、144 条条款与 24 题离线开发集继续作为可复现实验基线，在线库与离线草案库分开统计。
- 客户检索排除草稿、内部政策、撤回、被替代以及不在有效期内的资料。
- 当前界面发布即生效、替代或撤回时结束，未实现未来预约发布和历史订单适用规则选择。
- 管理员与客户列表仍显示最近 100 篇；检索目录使用独立游标分页，原文页面按 ID 读取，不受列表限制。
- 不自动公开新编草案、不导入私有资料、不调用用户的真实付费模型做验收。

## 评测安排：随功能推进

| 阶段 | 同步验证 |
|---|---|
| 当前 P3a | 草稿隔离、内部权限、版本替代、撤回、分页完整、引用原文、生成时来源失效 |
| 向量与 Hybrid | 固定题集的条款 Recall@5、不同表达召回、延迟、索引构建成本 |
| 重排 | 同一候选集下的排名变化、相关条款前移、额外耗时 |
| 证据充分性和补查 | 首次失败子集的新增正确数、补问和拒答、额外 token 与耗时 |
| 最终交付 | 场景族隔离的 holdout、端到端业务成功、引用支持率、消融与人工抽查 |

现有 24 题已被观察，是开发集。85.4% 是此前草案词法检索的条款召回，不能当成本轮线上问答准确率，也不能直接代表后续大库效果。金标中的等价条款遗漏要版本化修订，保留旧报告；不只挑失败题改到通过。

复现：按 `scripts/start-p2.ps1 -Build` 构建，`scripts/verify-p2.ps1` 运行完整测试并自动恢复正常模型模式。P3 浏览器测试使用显式 fixture 产生固定回答，但政策发布、MCP、MySQL 和引用原文均走真实本地服务。

## 本轮验证记录

- Java 构建通过，原有 12 项定向业务测试通过。
- Python/真实本地 MCP 回归 47 项通过，1 项真实模型测试跳过；其中新增 3 项验证来源撤回、引用校验前不输出政策正文、伪造引用不能成为有效来源。
- 原有 8 个浏览器场景通过；P3 两个专项在修正表单标签、发布完成等待和错误提示定位后通过。专项覆盖真实发布、检索引用、原文、修订替代、撤回失效，以及 205 条条款分页和内部资料隔离。
- 17 项 API smoke 与模拟退款状态、金额、审计一致性检查通过。
- 集成过程发现并修复了 MySQL `cursor` 保留字别名冲突；已有内容的修订表单补充明确字段标签。原文页面完成视觉检查，政策引用截图保存在忽略目录 `.local/screenshots/p3-policy-citation.png`。
- 验收使用合成账户和显式非 AI 引擎；未使用真实模型 Key。结束后恢复正常模式并撤回本轮测试遗留的已发布样例，保留审计性历史。
