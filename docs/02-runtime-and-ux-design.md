# Agent运行机制与前端设计索引

本文件保留早期设计编号，公开版说明以当前Aster实现为对象。具体运行链路、边界及代码入口已整理到[Agent指南](agent.md)和[系统架构](architecture.md)。

## 设计关注点

- 将会话身份、单轮运行状态、工具执行与最终回答分开管理。
- 把用户输入、检索正文与工具结果当作数据，不当作权限或系统指令。
- 有界历史与任务快照帮助处理连续问题，但不能替代价格、库存与政策的实时校验。
- 客户确认发生在明确的业务预览之后，服务端检查有效期、所属客户与消费状态。
- 界面展示可观察的工具进度、引用和最终回答；对失败、取消和重复事件分别处理。
- 复用公开框架和协议，新增业务与界面实现按来源清单记录。
